## Ce qu'est le service {#el-servicio}

all-draw est une application web permettant de créer des diagrammes et des modèles dans plusieurs
notations. Vous pouvez l'utiliser sans compte (vos données restent dans votre navigateur) ou avec un compte
(vos données sont stockées sur le serveur et peuvent être partagées). Ses fonctionnalités sont décrites
dans ce manuel.

## Faites vos propres sauvegardes {#tus-copias}

Nous effectuons des sauvegardes, mais le service ne remplace pas les vôtres. Exportez régulièrement ce qui
compte pour vous avec **Importer / Exporter → JSON d'all-draw** (`.alldraw.json`) : c'est un format ouvert
qui contient l'espace de travail complet et qui peut être réimporté ici ou dans n'importe quelle
installation d'all-draw. Les espaces locaux n'existent que dans votre navigateur : si vous les perdez, nous
ne pouvons pas les récupérer. Voir [historique](historial.md).
